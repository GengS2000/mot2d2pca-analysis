Generated by `make_publication_DA_imputation_figures.R` (R 4.5.1, tidyverse +
patchwork + ragg). All outputs live in
`simulation3_effect_tune/publication_figures_imputation_DA/`.

Method-level metric summaries only (one observation per
`effect_size × masking_fraction × data_condition`):

| DA method | Source file(s) |
|---|---|

| **MaAsLin2** | `results_maaslin2_compare_all_effects/maaslin2_metrics_summary_all_effects.csv` (per-file summary; `maaslin2_plot_metrics_summary_all_effects.csv` was identical — `n_files = 1` — and used only as a cross-check) |

## 2. Methods deliberately EXCLUDED

- **ANCOMBC2** and **LDM** results were never read and appear in no figure,
  table, or summary statistic. `results_ancombc2_compare/` and
  `results_LDM_compare/` directories exist on disk but are ignored. A hard
  `stopifnot()` guard verifies no `ancombc2`/`ldm` method ever enters the
  combined data frame, and `combined_metrics_clean.csv` contains exactly the
  four allowed methods (verified: 0 forbidden-string matches).

## 3. No taxon-level results used

All conclusions are based **only on method-level metric summaries**. No
taxon-level inference output was read. In particular, **ZIGMM taxon-level files
were not used** because that data was not completely saved; only the
method-level `nbzimm_zinb_metrics_summary.csv` confusion-count / metric rows
are used.

## 4. Data-cleaning rules

- **Condition standardization** → `data_condition ∈ {imputed, zeroed}`.
  - LinDA / MaAsLin2 / ZIGMM: taken directly from the `method` column.
  - **glmmPQL**: the `method` column is `NA`. Condition is inferred from
    `main_var` (fallback `file`): contains `imputed`/`y_imputed` → imputed;
    `zeroed`/`y_zeroed` → zeroed; contains `mask` → **dropped** (99 mask rows
    removed). This restores glmmPQL from 297 → 198 valid rows.
- **Effect/frac standardization**: `effect_name` kept as e.g. `group_effect_0p6`;
  `effect_size` numeric (0.6); `masking_fraction` numeric (0.1) parsed from
  `frac_0p1` (`p` → `.`).
- **DA method labels** standardized to: LinDA, MaAsLin2, ZIGMM, glmmPQL.
- **Undefined-metric handling**: when `n_called_diff = 0`, precision and FDR are
  mathematically undefined and remain `NA` in the source; F1 can also be `NA`
  when TP = 0. Such `NA` cells are kept in `combined_metrics_clean.csv` and are
  excluded pair-by-pair from each statistical test. This is why the effective
  `n_pairs` for ΔF1 is below 99 for some methods (e.g. LinDA ΔF1 n = 59), and
  the effective n is reported per test in `statistical_tests_summary.csv`.

## 5. Statistics

For every `da_method × effect_size × masking_fraction` cell the paired
difference `Δmetric = metric(imputed) − metric(zeroed)` is computed for F1,
recall, precision, FDR, TP, FP, FN, TN, specificity, accuracy
(`paired_delta_summary.csv`).

Per DA method and pooled across methods we run a **paired two-sided Wilcoxon
signed-rank test** and a **sign test** (`binom.test`) against the null Δ = 0,
reporting `n_pairs`, `n_nonzero`, median/mean Δ, proportion positive, and both
p-values (`statistical_tests_summary.csv`). The method-stratified results are
always retained alongside the pooled result. `compact_summary_table.csv` is the
condensed table requested in the brief.

## 6. Main figure panel meanings

- **A — ΔF1 heatmap** (4 facets, one per DA method; x = effect size,
  y = masking fraction; 0-centred diverging fill). Shows the full 99-cell
  landscape per method; green = imputed better. Demonstrates the result is not
  cherry-picked — improvement is broad, concentrated at higher masking
  fractions and weaker effect sizes where zeroing destroys the most signal.
- **B — F1 vs masking fraction** for representative effects (0.55/0.60/0.65/0.70),
  faceted method × effect. Imputed (teal) vs zeroed (grey) curves; imputed
  degrades far more gracefully as masking increases.
- **C — Recall vs FDR trade-off** (all conditions). Shows imputed reaching
  higher recall without an uncontrolled FDR blow-up.
- **D — Median Δ(TP, FP, FN)** per method: the mechanism. Method-dependent —
  some methods mainly gain TP (recall), others mainly lose FP (FDR).
- **E — Paired Δ distributions** (ΔF1, ΔRecall, ΔFDR) per method with the
  two-sided Wilcoxon P annotated.

Supplementary figures: **S1** full F1/recall/precision/FDR curves (all
conditions, per method); **S2** full ΔF1 / ΔRecall / ΔFDR heatmaps; **S3** full
TP/FP/FN/TN confusion-count curves.

All figures saved as vector **PDF** and **600-dpi PNG**; main figure width
7.2 in (≈183 mm, double-column).

## 7. Key conclusions (reported honestly, including nuance)

1. **penalized_2d2_pca imputation improves DA inference across all four model
   families.** Pooled across 354 evaluable pairs, ΔF1 median = +0.135
   (Wilcoxon P ≈ 5e-29; 79% of pairs positive); pooled ΔRecall median = +0.048
   (P ≈ 2e-28).

2. **Per-method ΔF1**:
   - LinDA: median +0.248, 75% positive, P ≈ 2e-5.
   - ZIGMM: median +0.353, **100% positive**, P ≈ 6e-18.
   - glmmPQL: median +0.106, 88% positive, P ≈ 7e-16.
   - MaAsLin2: median +0.024, ~neutral on F1 (P = 0.45) **but** ΔRecall
     median +0.048 highly significant (P ≈ 1e-10). MaAsLin2 is the most
     conservative method; imputation buys recall at some precision cost, so F1
     is roughly flat rather than worse.

3. **The improvement mechanism is method-dependent — reported as observed:**
   - **LinDA**: gain is **recall-driven** (ΔRecall median +0.76, 98% positive);
     FDR rises in a majority of cells (sign-test P = 0.006) but the large
     recall gain dominates, so F1 still improves. → more true taxa recovered /
     fewer FN.
   - **MaAsLin2**: also recall-driven, with a precision trade-off.
   - **ZIGMM** and **glmmPQL**: gain is instead **precision/FDR-driven** —
     imputation sharply reduces false positives (ZIGMM ΔFDR median −0.47,
     P ≈ 6e-18; glmmPQL ΔFDR median −0.14, P ≈ 2e-8) while holding recall.

   The unifying statement is therefore: **imputation shifts every method to a
   better recall–precision operating point**; whether that manifests primarily
   as +recall (LinDA, MaAsLin2) or as −FDR (ZIGMM, glmmPQL) depends on the
   method's baseline behaviour on zeroed data. We do **not** overclaim a single
   "more TP, no extra FP" mechanism, because for LinDA FDR does increase even
   though F1 improves.

4. **Consistency**: the F1 benefit holds in 3/4 methods individually and in the
   pooled test; the recall benefit holds in all four. The advantage is broad
   across effect sizes and masking fractions (Panel A, S2), not confined to a
   few hand-picked settings.
